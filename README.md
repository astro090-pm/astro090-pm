## Как я работаю

- **Гипотеза → проверка → решение.** CustDev, JTBD, приоритизация ICE, одна главная метрика на эксперимент.
- **От концепции до продакшена.** Концепция, бюджет, роадмап, команда разработки — включая продукты с нуля.
- **Бизнес-результат, а не фичи.** Выручка, конверсия, отток, удовлетворённость клиентов.
- **AI там, где он даёт ценность.** Предсказуемый процесс как скелет, агенты — где шаги зависят от данных; качество измеряется эвалами.
